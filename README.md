## noti-picker

**알림에서 내가 지정한 키워드가 포함되면, 무음 모드여도 별도 진동을 울려주는 안드로이드 앱**입니다.

### 기능
- **키워드 등록/삭제**
  - 메인 화면에서 키워드를 입력 후 `추가` 버튼을 누르면 저장됩니다.
  - 리스트 항목을 **길게 누르면 삭제**됩니다.
- **알림 모니터링**
  - 다른 앱에서 알림이 올라올 때, 제목/내용에 등록된 키워드가 포함되어 있으면 진동을 발생시킵니다.
- **알림 접근 권한 안내**
  - 앱 내 버튼을 눌러 `알림 접근 권한 설정` 화면으로 바로 이동할 수 있습니다.

### 사용 방법
1. 앱을 설치/실행합니다.
2. 키워드를 한 개 이상 등록합니다.
3. `알림 접근 권한 설정 열기` 버튼을 눌러 시스템 설정에서 이 앱의 **알림 접근 권한**을 허용합니다.
4. 이후 다른 앱에서 알림이 올라오면, 내용에 키워드가 포함된 경우 별도의 진동이 울립니다.

### 주의 사항
- **완전한 무음/방해 금지 모드**에서는 단말 제조사/OS 버전에 따라 진동이 제한될 수 있습니다.
- 알림을 읽기 위해, 시스템의 **알림 리스너 권한**이 반드시 필요합니다.
